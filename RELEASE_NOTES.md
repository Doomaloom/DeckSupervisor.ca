# Release Notes — Main Port Update

This release brings together a wide range of improvements designed to make session setup, roster management, printing, and day-to-day administration faster and easier.

## Highlights

- A simpler and more reliable roster import experience.
- Clearer session and dashboard workflows.
- More flexible masterlists with live previews and alphabetical layouts.
- Adjustable schematic previews and cover pages.
- Familiar, polished attendance sheets for every class level.
- More consistent roster, attendance, and report-card information.
- Faster document preparation with less reliance on the server.

## Easier CSV Imports

Roster imports now follow one streamlined process. Uploaded information is retained while working with a session, so staff can adjust locations without uploading the same file again.

Other import improvements include:

- Included Raw Locations can be selected from a dropdown based on the uploaded file.
- Duplicate and unnecessary upload fields have been removed.
- Combined locations, mini sessions, waitlists, and varied class schedules are handled more consistently.
- Import feedback is shown cleanly within the application instead of through disruptive browser popups.
- After a successful upload, users are taken directly to Manage Sessions.

## Clearer Session Management

The dashboard and session-management experience has been reorganized to make common actions easier to find and complete.

- Creating, selecting, reviewing, and editing sessions is more focused and easier to follow.
- Session dates, week labels, and mini-session information are displayed more consistently.
- Existing imported information stays connected when session locations are adjusted.
- Full-time and part-time session views behave more consistently.
- Signing out now returns users directly to the login page.

## More Powerful Masterlists

Masterlists now offer more control over both organization and appearance.

- Student rows now appear correctly in the live preview and final document.
- A live preview updates as formatting choices change.
- Age is included as a dedicated, centered column.
- Font size can be adjusted from 8 to 18.
- Borders, headings, alignment, and bold styling remain customizable.
- Column sizing is more consistent and easier to read.

Two layout choices are now available:

- **Class & Time** keeps students organized by their scheduled classes.
- **Alphabetical** combines students into A–Z sections and can sort by first or last name.

Masterlist options are arranged into tidy, collapsible groups. Schematic Coverpage appears first, and every group can be expanded or minimized independently. Time Header Style and Course Header Style stay collapsed until needed and open automatically when their corresponding headings are enabled.

## Better Schematic Planning

Schematics are easier to review and fine-tune before printing.

- A live preview shows the final layout before printing.
- Portrait and landscape orientations are supported.
- Scale can be adjusted from 60% to 120%.
- Instructor names can be highlighted for individual packets.
- One cover can be prepared for each instructor when needed.
- Student totals and class capacity information remain visible at a glance.
- Instructor packet covers preserve the selected orientation and layout.

## Improved Attendance Sheets

Attendance sheets now use the familiar class-specific designs staff already know, covering all 23 supported lesson templates.

- Every class level retains its own skills, headings, and assessment content.
- Front and back pages maintain their intended order.
- Paired classes print with both front sheets followed by both back sheets.
- Odd final classes remain complete two-page sheets.
- Private-lesson reference content is preserved and fits correctly.
- Day labels are easier to read.
- Intended line breaks and page breaks are preserved.
- Level-edited classes use the correct attendance template.
- Instructor packets can include schematic cover pages and blank backs.

Attendance sheets are prepared directly in the browser and open in the standard Chrome or Edge print dialog. From there, users can print normally or choose **Save as PDF**.

## Consistent Roster and Level Changes

Level changes now carry through more reliably across the application.

- Whole-class and individual-student level edits are supported.
- Editing a level no longer unexpectedly changes roster ordering.
- Updated levels are reflected consistently in rosters, attendance sheets, and report cards.
- Related level edits are kept together when attendance materials are prepared.

## Refined Reports and Documents

Masterlists, schematics, and session reports are now prepared in the browser with consistent fonts, spacing, page sizes, and document details.

- Previews and printed documents use the same information and formatting.
- Session reports retain their full staff, lesson, safety, facility, feedback, and project sections.
- Blank pages, rotated covers, and combined packets preserve the correct page size and orientation.
- Document titles and filenames are clearer and more consistent.

## A Smoother Everyday Experience

- Disruptive browser alert popups have been replaced with clean in-app feedback where a message is still helpful.
- Print options are better organized and easier to scan.
- Popup-blocked printing provides a clearer retry experience.
- Attendance sheets are assembled from the current roster information each time they are prepared.
- Additional safeguards and automated checks improve reliability across imports, sessions, rosters, masterlists, schematics, attendance sheets, and reports.

## Lower Running Costs

The service can now pause while it is not being used and automatically resume when needed. This helps reduce hosting costs without changing normal workflows. The first action after a long idle period may take a moment longer while the service wakes up; following actions should respond normally.

## In Short

This update makes the application easier to navigate, reduces repeated work, gives staff more control over printed materials, and keeps roster information consistent from import through final reports.
