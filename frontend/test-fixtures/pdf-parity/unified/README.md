# Unified attendance PDF references

These synthetic PDFs are the approved vector-rendering references for the shared
attendance specification in `docs/pdf/attendance-style-spec.md`. They contain no
user data. The suite includes all 23 templates plus paired, odd, non-adjacent,
dense, empty-roster, and private-pair packet cases.

Review the generated front and back contact sheets under `tmp/pdf-parity/` before
replacing these files. Historical Chromium fixtures remain in the adjacent
`historical` directory for migration diagnostics.
