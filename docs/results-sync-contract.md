# Results sync v1

All JSON uses camelCase. Apply `backend/supabase_results_sync.sql` after session-instructor migrations. Server device RPCs require SUPABASE_SERVICE_ROLE_KEY. Website RPCs use the authenticated caller. No participant names/contact data are persisted.

GET/PUT `/api/sessions/{sessionId}/result-identities`: `{schemaVersion:1,sessionId,datasetId,courses:[{sourceId,classId,instructorId,lessonDates:[],swimmers:[{sourceId,enrollmentId,matchKey,matchKeys?:[],active?:boolean}]}]}`. GET includes historical inactive enrollments with active:false; PUT active:false remains inactive. GET 404 before registration; read scoped by active assignment. Supervisor PUT preserves browser source IDs and immutable dataset/class/enrollment identities; omitted enrollments inactive. matchKey is opaque lowercase SHA256. Explicit supervisor POST `.../result-identities/reconcile` `{courseId,swimmerId,enrollmentId,matchKey}` adds an alias. GET `.../result-classes` returns supervisor-only `{classes:[{id,code,instructorId}]}` for initial mapping.

POST `/api/device-shares` accepts optional `sessionId`; authenticated bound packages require registry and add package `sync:{schemaVersion:1,sessionId,datasetId,instructorId,courses:[{sourceId,classId,swimmers:[{sourceId,enrollmentId}]}]}`. Server validates bindings and never trusts submitted sync metadata. Redeem returns `{package,sync:{schemaVersion:1,sessionId,datasetId,instructorId,courses,uploadToken,readToken,expiresAt}}`. Upload lasts 30 days; separate read token lasts 12 hours. Only hashes persisted. Each redemption issues independent grants. Closing share does not revoke grants. Guest/unbound packages remain import-only.

POST `/api/device-results/upload` Bearer uploadToken and POST `/api/sessions/{sessionId}/results` cookie-authenticated: `{schemaVersion:1,operations:[Operation]}` max 200. Operation `{operationId,sessionId,datasetId,classId,enrollmentId,recordId,kind:"attendance"|"attempt",action:"upsert"|"delete",baseRevision,lessonDate,curriculumVersion,payload}`. Attendance recordId `attendance:<enrollmentId>:<lessonDate>` payload `{status:"present"|"absent"|"unmarked"}`. Attempt recordId UUID; payload `{skillId,createdAt,submittedAt,results:[{subskillId,status:"successful"|"not_yet"}],timed?:{lapsRequired,lapsCompleted,elapsedMs}}`. Delete payload `{}`. Server validates full criteria against versioned curriculum and derives success. No free text/drafts/client-computed success. Timed benchmark skills require timing; only Splash7:10 (180000ms), Splash8:9 (360000ms), Splash9:11 (540000ms) allow timing. Success requires all criteria, completed target laps, and elapsed time within benchmark. One in-flight edit per record; first revision 1/base 0.

Response `{schemaVersion:1,receipts:[{operationId,status:"accepted"|"already_accepted"|"pending_review"|"rejected",revision,reason?}]}`. Each operation commits independently. Changed reuse rejected. Conflict retries remain pending_review. Pending review is durable, not silently applied. Only accepted/already_accepted/pending_review leave upload queue.

GET `/api/device-results` Bearer readToken and GET `/api/sessions/{sessionId}/results` (optional classId) return `{schemaVersion:1,records:[Operation & {revision,deleted,success,updatedAt}],conflicts:[{id,operation,current,resolved}],history:[{recordId,revision,record}]}` including tombstones. Upload tokens cannot read. POST `/api/sessions/{sessionId}/results/conflicts/{conflictId}/resolve` supervisor `{choice:"current"|"incoming",expectedRevision:number}` returns `{resolved:true}`. Incoming becomes new revision; audit retained. expectedRevision must match the latest accepted revision shown to the reviewer (0 if none), preventing a review from overwriting an unseen newer edit. Existing records remain correctable after enrollment removal; new records require active enrollment. Attempt skillId, createdAt and curriculumVersion remain immutable across corrections and tombstones. GET `.../result-grants` `{grants:[{id,instructorId,expiresAt,revoked}]}`; DELETE `.../result-grants/{grantId}` 204 supervisor-only.

Regenerate frozen criterion SQL with `python3 scripts/generate-result-curriculum.py /path/to/rec-tablet/catalog.json` after reviewing a catalog version change; benchmark constants track tablet benchmarks.go.

Every request rechecks current assignment scope, active instructor binding, grant expiry/revocation, and creator management rights. Grants never expand with reassignment.
