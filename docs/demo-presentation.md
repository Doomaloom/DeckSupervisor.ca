# DeckSupervisor Citywide IT Demo Presentation

Audience: citywide IT implementation review  
Recommended length: 15-20 minutes  
Story: save staff time by turning one roster export into a repeatable aquatics prep workflow  
Tone: neutral product voice; avoid technical language except security/privacy

## Slide 1: DeckSupervisor

**On slide**
- Faster aquatics session prep, cleaner handoffs, and supervisor visibility across facilities
- Built for repeatable pool-deck preparation
- Designed for part-time staff and full-time supervisors

## Slide 2: Why This Exists

**On slide**
- Aquatics prep work is spread across exports, spreadsheets, print screens, and manual notes
- Staff spend time formatting and checking materials instead of preparing the pool deck
- Supervisors need visibility without collecting files from everyone
- DeckSupervisor turns a roster export into a repeatable workflow

## Slide 3: Old Workflow Snapshot

**On slide**
- Excel schematic edits: schematic was printed from Excel; cells had to be moved manually
- CSV masterlist cleanup: masterlist was downloaded as CSV, cleaned up, then printed
- Xplor class printing: each class sheet had to be printed individually
- Manual file handoffs: coverage depended on files and explanations

## Slide 4: New Workflow Map

**On slide**
1. Upload roster CSV
2. Confirm detected session
3. Build schematic
4. Review rosters
5. Print materials
6. Share coverage
7. Supervisor oversight
8. Session planning

## Slide 5: Part-Time Step 1 - Upload CSV

**On slide**
- Start with the roster export
- The CSV becomes the source for the rest of the workflow
- One upload feeds session setup, rosters, schematic, and print materials

## Slide 6: Part-Time Step 2 - Confirm Detected Session

**On slide**
- Detected Tuesday session
- Facility, date range, time, and roster structure come from the export
- Less manual setup before staff can start preparing

## Slide 7: Part-Time Step 3 - Schematic

**On slide**
- Before: manually move cells in Excel
- Now: organize the session visually from imported classes
- The schematic becomes a deck-ready reference

## Slide 8: Part-Time Step 4 - Rosters

**On slide**
- Before: re-check the CSV masterlist every time
- Now: rosters are grouped and ready to review
- Class levels and custom roster decisions stay with the session workflow

## Slide 9: Part-Time Step 5 - Print Materials

**On slide**
- Before: print work was spread across Excel, CSV cleanup, and Xplor
- Now: one print center prepares session materials
- Less repeated formatting, fewer places to miss updates

## Slide 10: Part-Time Step 6 - Share Session Coverage

**On slide**
- No file handoff
- Coverage staff can access the right session context
- Access can be limited to what the coverage person needs

## Slide 11: Part-Time Workflow Summary

**On slide**
- One roster export supports the full prep cycle
- Less Excel formatting
- Less manual checking
- Less scattered printing
- Cleaner coverage handoff

## Slide 12: Full-Time Workflow - Supervisor Oversight

**On slide**
- Supervisors can see work across staff and sessions
- Team and term context replaces one-off file collection
- Useful for standardizing process across facilities

## Slide 13: Full-Time Step - Teams And Facilities

**On slide**
- Manage teams
- Track available locations
- Invite and organize staff
- Create a consistent operating structure across facilities

## Slide 14: Full-Time Step - Requests And Roster Oversight

**On slide**
- Review requests in one workflow
- Support staff without collecting separate spreadsheets
- Keep supervisor decisions connected to the session

## Slide 15: Full-Time Step - High-Volume Tools

**On slide**
- Built for higher-volume prep
- Reduce repeated setup for supervisor materials
- Supports consistency across staff

## Slide 16: Session Planner - Why It Matters

**On slide**
- Before the session starts, low-enrollment classes need decisions
- Higher-demand classes can replace underused pool time
- Planning needs cancellations, moves, calls, and email follow-up in one place

## Slide 17: Session Planner Step 1 - Find Pressure Points

**On slide**
- See which classes need attention
- Compare enrollment and waitlist pressure
- Plan changes before the session begins

## Slide 18: Session Planner Step 2 - Plan Moves And Alternatives

**On slide**
- Mark planned cancellations or class moves
- Find options for affected customers
- Keep decisions tied to the class

## Slide 19: Session Planner Step 3 - Calls, Emails, And Scripts

**On slide**
- Call scripts are ready
- Email sending is easier
- Call status and notes stay with the change
- Everyone works from the same plan

## Slide 20: Security & Privacy

**On slide**
- Sensitive customer details from uploaded CSVs are not stored in backend records
- CSV data is used for the local workflow
- Shared records store operational context like sessions, schematics, notes, and permissions
- Role-based access separates part-time and full-time workflows
- Coverage sharing is explicit and limited
